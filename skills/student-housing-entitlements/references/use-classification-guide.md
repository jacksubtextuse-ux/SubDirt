# Use Classification Guide — The Threshold Question

By-the-bed purpose-built student housing does not map cleanly onto most zoning codes' use categories.
The classification decision determines which districts allow the use, which paths exist, and sometimes
whether the project is viable at all — so it is analyzed **first**, explicitly, with the definitions
quoted. Getting this wrong in the project's favor is the single most dangerous error this skill can
make.

## The candidate categories

Work through these in order for the jurisdiction's code, quoting each definition that exists:

### 1. Multifamily dwelling / apartment
The correct and defensible reading for privately owned, market-rate PBSH in most codes: independent
dwelling units (kitchen + bath per unit), leased residentially, professionally managed. By-the-bed
*leasing* is a business practice, not a building type — the building is apartments.
- **Strengthens the reading:** full kitchens in every unit; standard residential lease instruments
  (even if severally by bedroom); no institutional affiliation; unit-based utility metering.
- **Weakens it:** shared kitchens serving multiple sleeping rooms; institutional dining; university
  master-lease or affiliation agreements (can slide toward "dormitory").

### 2. Dormitory
Usually defined by institutional character — operated by or affiliated with an educational
institution, and/or sleeping rooms without individual dwelling-unit facilities. Often permitted only
in a handful of residential/institutional districts and absent from commercial-district use tables
entirely. **If the jurisdiction classifies private PBSH as "dormitory," the available district set
collapses** — this is the make-or-break scenario to resolve at pre-application, in writing.

### 3. Rooming / boarding house, "congregate living," SRO
Codes with these categories sometimes catch by-the-bed products, especially where units rent
individual sleeping rooms with shared facilities. Typically heavily restricted, capped in size, or
conditional-only. Check the definition's hinge (separate rentable rooms? shared facilities? number of
roomers?) against the actual unit design.

### 4. A defined "student housing" use
A minority of college-town codes define student housing explicitly (sometimes with spacing/
concentration rules, sometimes as an overlay-only use, sometimes with per-bedroom parking). Where it
exists, it governs — read every standard hung off the definition, because these bespoke categories
carry bespoke burdens (occupancy registration, parking per bed, distance-between-projects rules).

## Occupancy-definition traps (check even when the building type is clearly permitted)

These operate independently of the use classification and are routinely missed:

- **"Family" definitions / unrelated-persons caps.** A code defining "family" as ≤N unrelated persons
  can cap a 4- or 5-bed unit regardless of the building's classification. Check the definition, any
  functional-family alternative, and any state-law preemption of unrelated-persons caps. A 4BR/4BA
  unit mix in a "max 3 unrelated" jurisdiction is a program-level conflict — surface it in the memo's
  executive summary, not a footnote.
- **Bedroom caps / bedroom-count multipliers.** Per-unit bedroom maximums, per-structure bedroom caps,
  or standards (parking, open space) that scale per bedroom rather than per unit.
- **Occupancy registration / rental licensing.** Some college towns require per-unit rental permits
  or occupancy certifications with inspection regimes — an operating cost and compliance item to flag
  (fee side belongs to the fees skill).
- **Short-term-rental and lease-term rules.** Rare, but check minimum lease terms where they exist —
  11.5-month academic leases are fine everywhere observed, but 5-month or semester leases can trip
  minimum-term rules.

## Resolving the classification

1. **Read the definitions article first** — never argue from the use table alone; the definitions
   decide which row of the table applies.
2. **State the reading this memo proceeds on** and the reasoning, as an interpretation (house rule:
   interpretations are labeled).
3. **Check how the jurisdiction has actually classified comparable projects** — the strongest evidence
   is a recent PBSH approval in the same jurisdiction and what use category its staff report used.
   Cite the staff report.
4. **If any doubt remains, make written confirmation the #1 pre-application item**: a zoning
   verification letter or a written determination from the zoning administrator. A verbal "should be
   fine" at the counter is not an entitlement basis — say so in the memo.
5. **If the jurisdiction's likely reading is unfavorable**, the classification question becomes a
   path question: which districts permit the unfavorable category, is a text amendment realistic, or
   does the unit design change (e.g., full kitchens, ≤N bedrooms) to fit the favorable category?
   Present the trade explicitly.
