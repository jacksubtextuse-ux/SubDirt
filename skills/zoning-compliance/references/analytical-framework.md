# Analytical Framework — Zoning Compliance Categories

This document defines every compliance category to check, what data you need, how to evaluate it, and what to flag. Work through these categories systematically for each site.

## 1. Site Information

| Check | Data Needed | How to Evaluate |
|---|---|---|
| Site Area | Total land area in SF and acres | Compare against minimum lot area for district. Flag if parcel assembly is involved. |
| Zoning District | Current zoning designation | Confirm from zoning summary or city records. Note if any parcels in assemblage have different zoning. |
| Overlay Districts | Any overlay designations | Extract from zoning summary. Overlays can modify height, use, design, open space requirements. |
| Comprehensive Plan | Future land use designation | Advisory only but influences PD negotiations and staff recommendations. Note alignment or conflict. |
| Parcel Assembly | Individual parcel data | If multiple parcels: list each with address, size, and zoning. Flag unconfirmed zoning. |
| Frontage Type | Street frontage classification (for form-based districts) | Determines ground floor use requirements, build-to lines, facade standards. |

## 2. Density & Use

| Check | Data Needed | How to Evaluate |
|---|---|---|
| Density Limit | Max units/acre or min SF/unit from code | Calculate: (land area SF) ÷ (SF per unit requirement) = max units. Compare to proposed. |
| Total Units | Proposed unit count | Direct comparison to density limit. Report % over/under. |
| Total Beds | Proposed bed count | Some codes regulate beds (bedroom caps). Even if no bed limit, report for parking calcs. |
| Unit Mix | Units by bedroom count | Affects parking ratios, bedroom cap triggers, design standard triggers. |
| FAR | Floor area ratio limit (if applicable) | Calculate: (total gross SF) ÷ (land area SF). Compare to limit. |
| Permitted Use | Is the proposed use allowed? | Multifamily/student housing may be permitted, conditional, or prohibited depending on district. |
| Ground Floor Use | Commercial required? | Some districts (especially mixed-use, downtown) require non-residential at ground floor. |
| Bedroom Cap | Max bedrooms per structure | Common in student housing codes. Often triggered by unit mix (e.g., "if 50%+ units have 4+ bedrooms"). |

## 3. Height

| Check | Data Needed | How to Evaluate |
|---|---|---|
| Max Height (ft) | Height limit in feet | Compare proposed building height. If not provided, estimate: stories × 12-13 ft/floor. Flag as estimate. |
| Max Height (stories) | Story limit | Direct comparison. Note if code uses stories, feet, or both. |
| Height Overlay | Any overlay that modifies height | Overlays can increase or decrease base district height. Apply the overlay-modified limit. |
| Height Bonus | Any bonus height provisions | Some codes offer additional height for design features, affordable units, setback increases. |
| Minimum Height | Minimum height at build-to line | Common in form-based/downtown districts. Usually 2 stories minimum. |
| Ground Floor Height | Clear height requirements for ground floor | May differ for residential vs. commercial ground floors. |
| Mechanical Penthouse | Does rooftop equipment count toward height? | Critical for buildings at the height limit. Tall Structures procedures may apply. |

## 4. Parking

| Check | Data Needed | How to Evaluate |
|---|---|---|
| Residential Ratio | Parking spaces per unit or per bedroom | Apply correct ratio by bedroom count. Calculate total required. Compare to provided. |
| Visitor Parking | Additional visitor spaces required | Often "1 per 5 units" or similar. Add to residential requirement. |
| Non-Residential Ratio | Parking for commercial/retail component | Apply per-SF ratio for the use type. May be exempt in downtown districts. |
| Maximum Parking Cap | Upper limit on parking | Some codes cap parking at 150% of minimum. Verify project doesn't exceed. |
| Bicycle Parking | Bike parking requirements | Often expressed as % of auto spaces or per unit. Increasingly common. |
| Parking Reductions | Available reductions (transit, downtown, shared) | Downtown districts often have reduced or eliminated parking requirements. |
| Structured vs. Surface | Any requirements on parking type | Some codes mandate structured parking above a certain density. |

### Parking Calculation Method

Be precise about which ratio applies. Common structures:

```
Studio/1-BR:     1.0 spaces/unit
2-BR:            1.5 spaces/unit
3-BR:            2.0 spaces/unit
4+ BR:           2.5 spaces/unit
Visitor:         1 per 5 units
```

OR (bedroom-based):
```
Per bedroom:     0.50 spaces/bedroom (for 20+ bedrooms)
Per bedroom:     1.0 spaces/bedroom (smaller projects)
```

The applicable ratio depends on the specific code. Always cite the exact table and section.

**If unit mix is not provided**, calculate parking using the most conservative ratio that could apply, then note that the actual requirement depends on unit mix.

## 5. Setbacks & Siting

| Check | Data Needed | How to Evaluate |
|---|---|---|
| Front Setback | Minimum front setback distance | From dimensional table. Note if there's a maximum (build-to line). |
| Side Setback | Minimum side setback distance | May vary by building type, number of stories, or adjacent use. |
| Rear Setback | Minimum rear setback distance | Often larger than side setbacks. |
| Build-to Line / RBL | Required building line percentage | Form-based districts: % of facade that must be built to the designated line. |
| Ground Floor Footprint | Maximum footprint per building | Some codes limit individual building footprints (e.g., 34,000 SF max). |

## 6. Design Standards

| Check | Data Needed | How to Evaluate |
|---|---|---|
| Facade Length | Maximum facade length per elevation | Common limit: 200 ft. Articulation or breaks required beyond this. |
| Building Articulation | Required facade breaks or offsets | Usually triggered at a certain building length. Specific depth/frequency varies. |
| Transparency | Minimum window/glazing percentage | By floor (ground floor often higher). Usually 30-60% at ground level. |
| Entrance Spacing | Maximum distance between building entrances | Common in form-based codes. |
| Material Standards | Required exterior materials | Some codes restrict vinyl, EIFS, or require masonry percentages. |
| Roof Standards | Flat vs. pitched, screening for mechanicals | Varies by district and building type. |

## 7. Neighborhood Protection / Transitions

| Check | Data Needed | How to Evaluate |
|---|---|---|
| Height Step-Down | Maximum height near lower-density zones | Common: building height limited to 24-30 ft within 25-50 ft of R-1/R-2 lot lines. |
| Setback Increase | Additional setbacks near residential | Some codes require increased setbacks adjacent to single-family districts. |
| Screening/Buffering | Visual screening requirements | Fencing, landscaping, or architectural screening between uses. |
| Light/Glare | Restrictions on lighting near residential | Foot-candle limits at property lines. |
| Noise | Limits on noise-generating elements | Mechanical equipment, parking structures, outdoor amenities. |

## 8. Landscaping & Open Space

| Check | Data Needed | How to Evaluate |
|---|---|---|
| Landscape Area | Minimum % of total land area | Common: 15-25% of total site area. Calculate required SF. |
| Open Space per Unit | SF of open space per dwelling unit | May vary by unit size. Balconies/rooftops may count (often up to 33%). |
| Street Trees | Required street tree plantings | Per linear foot of frontage or per parking space. |
| Parking Lot Landscaping | Interior and perimeter requirements | Islands, perimeter buffers, tree canopy coverage. |
| Buffer Yards | Required buffers between incompatible uses | Width and planting density depend on adjacent use differential. |
| Green Space (Overlay) | Special overlay requirements | Some campus/university overlays require 50%+ green space. Check applicability. |

## 9. Entitlement Pathway Assessment

After completing the compliance check, make a determination:

### By-Right Feasible
- All critical standards (height, density, use) are PASS or PASS*
- Parking deficit is <20% and addressable through available reductions
- No design standard violations that require legislative relief

### Variance / Conditional Use May Suffice
- One or two standards require minor relief (<25% deviation)
- The code provides a variance or conditional use pathway
- The deviation doesn't fundamentally change the project character

### PD Rezoning Required
- Height deviation >25% (e.g., 8 stories proposed in a 35 ft district)
- Density deviation >50% (e.g., 266 units proposed where 31 are allowed)
- Multiple critical standards need simultaneous relief
- The project represents a fundamentally different building type than the district allows

### PD Deviation Quantification
When PD is required, calculate the deviation for each standard:

```
Deviation % = ((Project Value - Base Limit) / Base Limit) × 100
```

For example:
- Height: 8 stories vs. 35 ft limit (assume ~104 ft) → (104 - 35) / 35 = 197% deviation
- Density: 266 units vs. 31 units max → (266 - 31) / 31 = 758% deviation
- Parking: 394 provided vs. 665 required → (665 - 394) / 665 = 41% reduction

## 10. Source Documentation

Every analysis must end with a source documentation section listing:

1. Each document consulted: title, date, and whether it was from the user's folder or online
2. Key section citations used in the analysis
3. Any citations that could not be independently verified
4. A clear statement: "All sources were provided in the user's folder. No online sources were used." OR "The following online sources were consulted: [list with dates accessed]."

**Online sources must be flagged prominently.** The user's preference is for folder-provided sources to be the primary basis of analysis.
